# Search presentation and metadata — 16 October 2026

## Website

Every public product, course, lesson and blog page has its own title,
description, HTTPS canonical URL with the site's trailing-slash convention,
Open Graph URL/image and Twitter summary card. Sitemap URLs use the same
canonical convention. Account and authentication pages remain noindex and
outside the sitemap.

The home page identifies the website and native software. Courses identify
free Academy offerings with the registration requirement stated. Blog articles
have BlogPosting metadata, their real publication dates, named authorship and
article images. Course, lesson and article paths have BreadcrumbList data.
Registration-restricted lessons retain the access markup and approximately 30%
guest preview; SEO does not expose lesson answers or private media.

A production Next.js build, TypeScript checking and the five existing account,
content and preview tests passed. An HTTP audit verified all 763 sitemap pages:
200 responses, one H1, canonical/social metadata, zero duplicate titles and
valid JSON-LD. It also checked noindex account pages and unauthenticated media
denial. Live deployment verification is recorded separately after publication.

## App Store

The 1.1.1 draft retains the name **Crabrix: Rust Compiler**, with the subtitle
**Offline IDE & coding lessons** and a full 100-character keyword field.
Primary category: Developer Tools; secondary: Education. The description
separates local compiler capabilities, supported Cargo dependencies, offline
course downloads, optional Apple services and the free website account.

Two custom product pages are prepared: Rust Academy and Rust Compiler.
Each has a feature-specific promotional message and relevant search keyword
mapping. Academy leads with learning/lesson screenshots; Compiler leads with
the native editor. Header and Search Results creative assets are included.
Exact assets, page URLs and review status are recorded in the release evidence.

These changes provide accurate indexing and presentation signals; no ranking
or search-placement outcome is asserted.
