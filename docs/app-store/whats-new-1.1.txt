Crabrix 1.1 adds the full Academy as individual offline downloads, 46 open Code Examples, and a project workspace with nested files and in-file search. The iPad editor has a searchable header; iPhone Duo keeps the project name, code tabs, shortcuts, and keyboard together. Output now shows clear results for completed, empty, stopped, and failed runs. This update also adds a Cyberpunk theme, optional app protection, local builds for supported Cargo packages, and optional Game Center sharing.
