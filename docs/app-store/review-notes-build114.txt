Build 114 adds native Git and full repository transfer to 1.1.3. Publication is manual. No app account is required; website Academy accounts are separate.

Native Git: open a project → Project settings → Local Git. Start history, select main.rs, enter author name/email/message and commit. History shows actual commits and previews. Restore is explicit. Branch switching requires a clean tree. Git uses bundled libgit2 1.9.7 compiled into the signed app, not a downloaded executable or general shell. Original licenses/notices and complete corresponding source export are bundled offline in Settings.

Public HTTPS: before initialization, enter https://github.com/octocat/Hello-World.git and Clone as a new project. This README-only repository demonstrates acquisition/history without execution. Remote → Fetch preserves editor source and HEAD. Pull accepts clean fast-forwards; Push explicitly sends committed history. Only canonical GitHub HTTPS URLs with platform certificate verification are accepted. SSH, LFS, submodules, rebase, arbitrary hooks and force push are unsupported. Stop and bounded transfers are available.

Private access is optional and user supplied: repository-scoped GitHub username/token are saved only by Save access on this device in unlocked-only, device-only Keychain. Remove saved access deletes the entry. Tokens never enter source, Git config, exports, terminal history, compiler input or Shared. No private credentials are required for review.

Transfer: Changes → Save the complete repository → Prepare repository export → Save or share. Opening .crabrixrepo from Files creates a new local copy with real commit IDs, branches, worktree bytes and modes. Archives validate bounded inventories, digests, paths and Git objects; imported config is rebuilt before opening. Credentials and package caches are excluded. Source ZIP and .crabrixproject retain text-project scope. Preserved binary resources support local include_bytes!, Debug and cache identity; Git metadata never enters a guest.

Existing local tools remain: real bundled libtest selected-entry tests/filter/Stop; isolated panic-abort guests, ignored skipped and should_panic unsupported. No dev-dependencies, integration tests or doctests. Bundled rustfmt supports file/project/check/Undo with atomic revision guards.

Existing Debug steps supported Rust source and active async polls with bounded String/Vec/concrete-struct previews; no arbitrary memory/DWARF. Rust + Web: set src/main.rs line 7 breakpoint, Debug, Step/Continue, then click the generated counter. Compilation/execution stay in the local WASI interpreter. Browser npm preparation explicitly fetches source/licenses; Run/Check never downloads. No Node/Bun server, native addons or arbitrary package scripts; preview WebKit blocks external requests.

Optional Playgrounds default to one hour, maximum 24 hours, four participants and bounded text. Clients encrypt source/selection with AES-256-GCM; keys remain in URL fragments. Relay ciphertext is temporary RAM-only. Received code never executes automatically. No editor/Duo layout or entitlement redesign. Privacy, Terms and full licenses remain readable offline.
