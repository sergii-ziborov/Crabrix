Version 1.1.3 (113) adds selected-entry Rust unit tests and bundled rustfmt. All code compilation/execution remains on device in the existing bounded WASI interpreter; no JIT, backend compiler, remote shell or downloaded native executable. Release is manual. No app account is required; website Academy accounts are separate.

Unit tests: create a Rust project, add #[test] fn passes(){assert_eq!(2+2,4);} and #[test] fn fails(){assert_eq!(1,2);} alongside main. Open project settings → Unit tests, or Terminal cargo test. Real bundled libtest discovers tests; each selected case runs as an isolated, single-threaded WASM guest. A panic/assertion can abort that guest and later cases continue. Ignored tests are skipped; #[should_panic] is explicitly unsupported in this panic-abort profile, never passed. One selected entry, normal prepared dependencies, filter, --lib/--bin and -- --list are supported. Dev-dependencies, integration targets, doctests, custom harnesses and extra flags are rejected or described as unsupported. Stop interrupts the active guest. User tests do not award Academy progress.

Formatting: Project settings → Format current Rust file / Format project Rust files, or cargo fmt / cargo fmt --check / rustfmt path.rs. A pinned real rustfmt WASI reactor is bundled as signed app data and runs in WasmKit, off the UI thread. It never executes project Rust or fetches configuration/tools. It respects edition and a documented root-config subset; unsupported options and parse errors preserve source. File/project replacement requires the original revision and file budgets. Undo and check-only are available. Full notices and unmodified MPL dependency source are bundled for offline reading/export; website copies are available at https://crabrix.com/licenses/.

Existing Debug: create Rust + Web, set a breakpoint at src/main.rs line 7, choose Debug Rust project, Continue/Step/Continue and click the generated counter. include_str!/include_bytes! preserve source resource bytes. Instrumentation uses a separate snapshot and never replaces the editor. Bounded String/Vec/concrete-struct previews and active async polls are supported; const bodies, dependencies and macro internals are not stepped. Custom Debug implementations are not called.

Existing sharing: optional 1/4/12/24-hour guest links, one hour default, live text/cursors/selections. Clients encrypt with AES-256-GCM; keys remain in URL fragments. Relay ciphertext is RAM-only with expiry, no account/database/backups; restart can end rooms early. Limits: four participants, 16 files, 64 KiB/file, 128 KiB total. Received code is visible/editable and never runs automatically. Execution is local in each client.

Existing browser npm preparation fetches integrity-verified editable source/licenses explicitly. Run/Check do not download. Node/Bun servers, native addons, lifecycle scripts and arbitrary plugins are not executed. Browser output runs in nonpersistent WebKit with external requests blocked and no native writing bridge. Rust remains in the WASI sandbox. Save/recovery, hidden files and compile-only cargo build remain. No editor/Duo geometry or entitlement changes. Original licenses, Privacy and Terms remain offline in Settings.
