Crabrix 1.1 (50) is the latest Xcode Cloud archive, built with the iOS 27.1 SDK to include the Duo hinge layout. The native compiler and runtime remain bundled and unchanged by course downloads. The app needs no login, website account, paid course unlock, or reviewer credentials. Website Academy accounts are a separate free reading service.

REVIEW PATH
1. Open Learn on a fresh install. Seven courses and Code Examples are offered individually; no course is silently installed. Download Rust Basics (network required once), then open a lesson. Its text, code formatting, example and illustration remain available offline.
2. Open its starter in Code to create a separate project, then Check and Run. Output distinguishes completed, empty, failed and stopped results. The compiler is the source-built Rust 1.96.0-dev toolchain pinned to crabrix-rust-2026-10-02.1, targeting wasm32-wasip1. No server compiles user code.
3. In Learn, download Code Examples. All 46 projects can open their guide and source preview without a quiz/unlock. Open in Code creates a durable copy with its own README. Updating or removing course material never replaces that project.
4. My Courses/Learn offer Refresh, Update and Update all when the signed catalog has a newer compatible course. Updates are data-only: text, media, questions and editable source. They preserve progress and project copies; an open lesson stays on its previous snapshot until reopened.
5. Settings → About Crabrix contains full offline About, Privacy Policy, Terms of Use, Educational content rights, and Application source license. Apple Standard EULA is linked separately. Open-source licenses show current resolved packages; Compiler and sysroot dependency notices opens a searchable, offline 1,592-package source inventory plus original primary licenses. Website and GitHub use the same authored legal copy.
6. Profile contains the off-by-default Game Center switch. Local learning works without it. If enabled and authenticated, numeric rating and achievement progress go to Apple's service; the app has no proprietary account or leaderboard server. Disable to stop future submissions while retaining local progress.

NETWORK AND OFFLINE LIMITS
Course downloads and public GitHub imports require a connection. Cargo packages require initial resolution/download or an existing local pin. Supported prepared dependency graphs can rebuild offline. The user program's WASI sandbox has no network import. Build scripts, procedural macro crates, native linking, debugger and cargo test are unsupported. Examples and compatibility checks do not promise arbitrary crate support.

CAPTURES AND CONTENT
The en-US screenshot sets cover iPhone 6.9, iPad 13 and iPhone Duo. Current Academy content has 142 Rust lessons and 600 Atlas steps (200 challenges), with expanded explanations and inline code markup. Text and illustrations have content rights separate from MIT-licensed course tooling; private practice with starter/example code is permitted. The app is a one-time purchase with no subscription, advertising, analytics SDK or in-app purchases.

Existing learners keep their signed offline transition courses after upgrade. Optional Face ID/device passcode locks the local workspace. Report a problem opens an editable draft in the user's mail app and sends nothing by itself.
