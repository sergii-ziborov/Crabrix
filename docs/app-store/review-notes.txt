Crabrix 1.1 (10) reviewer notes — prepared for tester validation.

Crabrix is a native Rust development and learning environment. No account or
subscription is needed. The compiler, WebAssembly runtime, and WASI sysroot
are bundled in the app; neither compiler nor runtime is downloaded on device.

TO SEE IT COMPILE
1. Projects → current project card → Run. The project workspace opens on Code;
   the result appears in Output. Select a different file to return to Code.
2. Edit the string in main.rs and Run again to see a fresh local compilation.
3. Open the bundled Basics course in Learn. To inspect the borrowing lesson,
   download Ownership after confirming its shown size, open its starter as a
   project, inspect the E0502 diagnostic, repair the source, and Run. Lesson
   hints are available in Output.
4. Learn → Examples opens 46 editable Rust projects from the signed Projects
   CoursePack. On a fresh install, confirm the shown size to download that
   pack first. Open an example to create a separate copy in My Projects;
   edit and Run that copy. Its Rust source is visible to the user.

COURSES AND DOWNLOADS
Learn lists six Rust courses and Algorithm Atlas, with Examples under Academy
rather than Projects. A fresh installation opens Basics offline and offers
the other six as downloads. An update with legacy
progress activates all seven transition packs offline from the app bundle.
Learn → Check for course updates reads a
signed public catalog. A new version shows its download size before the user
confirms. A verified CoursePack contains learning data, media, and editable
Rust starter source; it cannot update the compiler, runtime, or executable
validator logic. Course updates preserve separate user projects and progress.
The catalog is served from raw.githubusercontent.com; archive assets are
served by GitHub release hosts. An unavailable catalog does not disable an
installed course.

PROJECTS AND PACKAGES
My Projects opens the project manager. New Project offers templates and
user-initiated imports from GitHub or Files/iCloud Drive. Cargo packages are
managed inside the open project. For a supported package, downloaded source
can be inspected and copied into a project with Vendor & Edit, then compiled
under a distinct local fingerprint or reset to the registry source.

SANDBOX AND PRIVACY
Programs run in a bounded, network-free WebAssembly sandbox. Compiler source,
sysroot, and registry mounts are read-only; compiler output and temporary
paths are separate. There is no cloud compilation, required login, analytics
SDK, or upload of user projects and progress. Course, crate, and GitHub
downloads make ordinary HTTPS requests to their respective hosts.

OPTIONAL APP PROTECTION
Settings offers device authentication for a local app lock, and Auto, Light,
Dark, and Cyberpunk appearances. The app does not request a Face ID enrollment
or create a remote account.

This build uses the pinned artifacts-test-7 rustc/sysroot. The public
CrabrixRuntime fork is based on WasmKit 0.4.1. Its iPhone and iPad screenshots
were captured from the matching Release Simulator source on 2 October 2026.
Physical-device tester results must be checked before App Review submission.
