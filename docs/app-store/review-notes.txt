Crabrix is an educational offline Rust compiler and local project editor. No app account is needed. The Rust compiler is bundled and produces WebAssembly executed by a bounded interpreter on the device; no remote compiler, JIT or downloaded native executable is used. New std-only build scripts execute in the same local WASI environment; host subprocesses, native linking and procedural macros are not supported.

To test the web lab: Projects > New Project > Web Page > Run. Tap the counter; HTML/CSS/JavaScript are local assets in a separate WebKit preview with external network blocked. Rust Web Generator creates the same assets using the bundled compiler. Web errors appear in Problems. TypeScript highlighting does not transpile TypeScript.

Courses and examples download once and remain readable offline. Website Academy login is separate and not required in the app. Preparing a new crate or importing GitHub source requires a network connection; compilation stays on device. Optional Game Center is off by default. Optional Apple Intelligence runs on device only where available; local completion works without it. Existing iPhone/iPad/Duo layouts are preserved. Documentation: https://crabrix.com/guide/ .
