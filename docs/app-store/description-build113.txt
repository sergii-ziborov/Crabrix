CARGO ON DEVICE
Resolve up to 2,048 Cargo packages, verify source checksums and pin archives for offline rebuilds. Standard-library-only build scripts run as bounded WASI guests. The target is wasm32-wasip1. Native linking, host subprocesses, separate build-dependency graphs and procedural macros remain unsupported. Arbitrary desktop repositories may not build. Selected-entry unit tests use real local libtest with filtering and isolated failures. Dev-dependencies, integration tests and doctests remain unsupported.

BROWSER PROJECTS AND NPM IMPORTS
Create HTML/CSS/JavaScript pages, generate them with Rust, or import browser projects with package.json. Explicit npm install/ci saves imported modules and licenses as editable local source. Run/Check then build without fetching packages.

Build JavaScript, TypeScript syntax and JSX/TSX locally. Supported npm dev/start/build/check commands map to browser operations. Preview runs in isolated WebKit with external requests blocked. TypeScript is transpiled without type checking. Node/Bun servers, arbitrary package scripts, build plugins and native addons are not included.

LOCAL RUST DEBUGGER
Set breakpoints, step through Rust and async functions, and inspect frames, String, Vec and concrete struct previews locally. Const bodies, macro internals and arbitrary memory inspection remain outside scope.

TEMPORARY PLAYGROUNDS
