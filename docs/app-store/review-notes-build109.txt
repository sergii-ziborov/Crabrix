Version 1.1.3 (109) fixes a debugger preparation error in the built-in Rust + Web template. It retains the local Rust debugger, temporary guest Playground sharing, browser source preparation, compiler acceleration and the 2,048 Cargo-package ceiling. Release is manual.

Reproduce the fix: create Rust + Web, set a breakpoint on src/main.rs line 7, open project actions and choose Debug Rust project. Continue to line 7, Step over the app.js write, and Continue. Output displays the generated offline HTML/CSS/JavaScript page; its counter increments. include_str! and include_bytes! now preserve original resource bytes, including Rust source included as data. Editable project source is never replaced with generated Debug code.

Debug uses a bundled Rust parser and instruments a separate local snapshot, compiled by the bundled WASI compiler. Checkpoints pause only the background interpreter queue. The parser never evaluates project code as JavaScript. Sync/async stepping, active-poll call frames and bounded String/Vec/struct previews are supported without calling custom Debug implementations. Borrowed/moved/captured values may be omitted; generic/packed/conditional fields can stay opaque. Const bodies, dependencies and macro expansions are not stepped internally. App Tokio current-thread tasks, timers and channels work offline; browser compilation uses std/local modules. See https://crabrix.com/guide/.

Share Playground creates an optional 1/4/12/24-hour room, one hour by default. Open its edit link in the public https://crabrix.com/playground/ or another Crabrix app. Text edits, cursors and selections synchronize. Received source is visible/editable, never runs automatically, and can be saved locally before expiry. HTTPS Universal Links and Open in Crabrix are supported. No app account is required; website Academy accounts are separate.

Clients encrypt text with AES-256-GCM; keys stay in URL fragments. The relay cannot decrypt code. Bounded ciphertext stays in RAM only, never accounts, files, databases or backups, and expires within 24 hours; restart can end rooms early. Limits remain four participants, 16 text files, 64 KiB/file and 128 KiB/project. Images and dependency archives are excluded. All compilation/execution is local: no backend compiler, remote shell or downloaded native executable.

Optional npm install/ci fetches browser source from the public npm HTTPS registry, verifies archive integrity and keeps editable source, manifests and original licenses. Run/Check never download packages. Supported npm commands map to browser operations; arbitrary scripts, lifecycle hooks, Node/Bun/Vite servers and native addons are not executed. Trusted tools run on a serial JavaScriptCore worker; user plugins are not evaluated there. Generated browser code uses the existing nonpersistent WebKit preview with bounded immutable assets, CSP, external requests blocked, and no shell or native writing bridge. Example and steps: https://crabrix.com/guide/#browser-packages.

Rust stays inside the existing local WASI sandbox. No UI geometry or entitlement change is introduced. Original licenses, Privacy and Terms remain available offline in Settings and on the website.
