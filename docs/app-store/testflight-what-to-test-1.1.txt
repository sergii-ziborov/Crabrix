Crabrix 1.1 (Xcode Cloud build 37): please focus on the current project editor, Duo keyboard layout, in-file search, and run results.

New in build 37: on standard iPhone and iPad, Code and Terminal no longer show the redundant keyboard-dismiss button at the right edge of the bottom tab row. Duo keeps it. Please check both devices with the keyboard open and closed.

1. On iPhone Duo, open Projects → current project. In portrait and laptop posture, check that the compact header shows the project name and Find in file without touching the system clock. The editor tabs stay together at the bottom. With the keyboard open, Code tabs, Rust shortcuts, and the keyboard should sit together without a large gap or overlap. Use Hide to dismiss the keyboard.
2. Switch to Terminal. The command field should take focus and open the keyboard every time. Change between Code and Terminal: tabs and keyboard controls should stay visible without jumping. In landscape, use the visible keyboard dismiss button. Switch to Problems and Output and confirm the keyboard can close so those panels use their full height.
3. On iPad, open a Rust file and use Find in file in the editor header. Open the project file drawer and check it reaches the dock without an unused lower gap.
4. Run a project that prints text, one that prints nothing, and one that fails. Output should clearly show completed, empty, stopped, or failed results, any stdout/stderr, and a usable Run again button. Stop a long run and start the next one; it should not remain stuck.
5. On a fresh install, Learn should offer seven course downloads plus 46 open Code Examples. Download Rust Basics and Code Examples. Open a lesson and an example, inspect the source preview, then Open in Code to make an editable project. Restart offline: installed lessons and saved projects should remain. Remove a download; copied projects and progress must remain.
6. In My Projects, create a project and a nested Rust file. Test Files and GitHub import, reopen the project, and confirm files persist. For Cargo, add a supported package such as syn 3.0.6 and Run; try Fix syn for local build on an older plain-syn project.
7. Check Cyberpunk across Learn, Projects, the editor, and Settings. Optional Face ID/device-passcode protection and the off-by-default Game Center switch require a signed physical device. If testing Game Center, turn it on, open Apple's leaderboard and achievements, then turn it off; local progress and rating must remain.

Please report device, iOS version, project or course, and reproduction steps. The compiler and runtime are bundled; course downloads contain readable learning data and editable source, not executable updates.
