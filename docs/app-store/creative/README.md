# Crabrix App Store creative assets

These are original illustrated assets for the 1.1 product page. They depict the existing Learn, Code, Run, and Output workflow. They are not captured app screenshots and contain no performance claim.

| File | Placement | Pixels |
| --- | --- | --- |
| `crabrix-header-3840x1646.png` | Product page header | 3840 × 1646 |
| `crabrix-search-1920x1280.png` | Search results | 1920 × 1280 |

On macOS with Pillow installed, edit and regenerate them with `python3 scripts/build_app_store_creative.py`. The exact files uploaded for build 24 are identified by SHA-256 in [the upload record](../creative-upload-2026-10-08-build24.json).

The two original creative assets (Product Page Header and Search Results) were
verified in App Store Connect on 10 October 2026 as Waiting for Review. They
are illustrations rather than application screenshots; actual current iPhone,
iPad and Duo captures live under `../screenshots/` and are synchronized with
website and app README files. The latest selected native build is recorded in
[submission status](../submission-status.md).
