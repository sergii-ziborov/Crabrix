Learn Rust, then make it run. Crabrix brings a native Academy and a real coding workspace to iPhone and iPad. Read a lesson, open its starter as your own project, check actual rustc diagnostics, and run the result locally. The compiler ships in the app: no cloud compilation or app account is required.

ACADEMY, AVAILABLE OFFLINE
Seven courses cover Rust Basics, ownership, traits, systems topics, Cargo projects and interview preparation. Algorithm Atlas teaches 200 reusable patterns through 600 ordered steps. Together the Academy has 742 lessons and steps with expanded guidance, inline code formatting, syntax-highlighted examples and illustrated explanations.

Choose individual courses to download; installed lessons remain readable offline. Signed content updates appear in Learn and My Courses with an Update button and Update all. Lesson corrections preserve existing progress and editable project copies. Removing a course keeps your projects and earned progress. The companion Academy uses a separate free website account; no app account is needed.

46 OPEN CODE EXAMPLES
Download the separate Code Examples path and explore every project in any order. Each stop has its own illustrated guide, source preview and README. Open in Code makes a durable, editable copy in My Projects. The first course or example download needs a connection.

PROJECT WORKSPACE
Work with files, syntax-aware editing, in-file search, real compiler diagnostics, and Code, Problems, Output and Terminal views. The editor supports indentation and paired syntax. Check finds compiler errors; Run compiles and executes the program in a bounded WebAssembly sandbox. Problems includes compiler and dependency setup errors. Output shows text, visual results and build stages. A package sheet lists downloads, verification, failures and dependencies.

My Projects manages local work. New Project offers templates and imports from public GitHub repositories and Files. Share or export your projects when you choose. iPad has a file sidebar and search. iPhone Duo adapts the header, coding tabs and keyboard controls to its fold layout.

SUPPORTED CARGO DEPENDENCIES
Add crates.io dependencies in Cargo.toml. Resolve up to 2,048 dependency packages, verify source checksums, build on device and pin archives for offline rebuilds. Standard-library-only build scripts run as bounded WASI guests. Native linking, host subprocesses, separate build-dependency graphs and procedural macros remain unsupported. The bundled compiler targets wasm32-wasip1; arbitrary desktop Rust projects may not build. There is no debugger or cargo test harness.

PRACTISE AND PERSONALISE
Quick Practice, Term Train and Code Recall reinforce the curriculum. Progress, rating and achievements are earned locally. Optional Game Center is off by default; enable it in Profile to share your numeric rating and achievement progress with Apple. Disabling it keeps local progress. 

LOCAL WEB LAB
Create HTML/CSS/JavaScript pages or generate them with Rust, then Run in an offline WebKit preview. Browser errors appear in Problems. External network is blocked; TypeScript is highlighted, not transpiled. This is not a TCP server.

Choose Auto, Light, Dark, Amber Circuit or Cyberpunk appearance. Optional Face ID or device-passcode protection locks the app when you leave it.

YOUR CODE STAYS ON YOUR DEVICE
No advertising, analytics SDK or cloud compiler. Projects, answers, detailed learning history and compiler output stay local unless you export or share them. Game Center is an optional Apple service. Requested course downloads, crates.io searches and packages, and public repository imports use the network; their hosts receive ordinary connection information. After downloading lessons and preparing needed dependencies, study and builds can work offline.

About, Privacy, Terms and full third-party licenses are readable offline in Settings. Your original code remains yours. One purchase; no subscription or in-app purchase is required.
