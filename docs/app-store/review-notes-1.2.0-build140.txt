Crabrix is a Rust programming and learning environment. No account or sign-in is required. Rust source is visible and editable; compilation and execution use the bundled local compiler and bounded WASI runtime.

What is new in 1.2.0 (it replaces 1.1.9, which was withdrawn from review before release, and includes all of it):

1. Connect my progress (optional, off until the user turns it on). Learn → "Learn with your AI agent" → Connect my progress. The screen lists exactly what is shared (completed lesson IDs, the current and recent lessons, installed course names with counts, up to 30 weakest practice topics, and the lesson plan the user's agent sent) and what is never shared (answers, code, projects, XP, account data). Tapping Connect creates a random link on https://crabrix.com: the progress snapshot is encrypted on the device with a key that exists only on the device and in the personal URL shown to the user; crabrix.com stores only ciphertext and token hashes. The user copies the URL into an AI client they already use (Claude, Claude Code, Codex, Cursor) as a custom MCP connector. The agent can read the progress and send lesson suggestions, which appear at the top of Learn as "From your AI tutor" with Open and dismiss buttons; it cannot complete lessons or change anything else. Disconnect deletes the link and all data on crabrix.com. To review without an AI client: tap Connect my progress → Connect, see the personal URL with Copy/Share, then Disconnect. The app contains no AI model and sends no prompts or code.

2. Two bridge courses. In Learn, download "Rust for C Developers" or "Rust for Node.js Developers" (the signed catalog is bundled). Each lesson shows C or JavaScript/TypeScript next to Rust. Completing a bridge lesson marks the Academy lessons it covers as "Known from C" / "Known from Node.js"; those marks count toward the path but give no XP or achievements. Rust Basics starts with a new lesson, "What Rust Is".

3. Learn with your AI agent: setup steps and prompts for connecting an AI client the user already has to Crabrix Academy, a public read-only lesson service at https://crabrix.com/mcp/academy. Each lesson has a "Learn this lesson with AI" button that copies a prompt with only that lesson's public title, ID and address. When the screen opens, the app reads https://crabrix.com/api/academy/v1/status.json (no identifiers) to learn whether the features are paused; offline, the screen still works.

4. iPhone code screen: while a project is open in portrait, Code, Problems, Output and Terminal replace the tab bar; close the editor with × to return. Flashcards ask each lesson's own questions. Course cards in Learn are swiped from right to left to reveal Remove.

Existing progress, answers, projects, Flashcards and Atlas recordings are retained after the update. Apart from the optional, user-initiated Connect my progress (encrypted, deletable at any time), the app sends no personal data; the rest of the app works offline.
