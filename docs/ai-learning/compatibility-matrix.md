# Compatibility matrix — Academy MCP vs existing Crabrix

Rule for every row: the Academy MCP and Academy API **read only public lesson/example content** and
**never read or write progress, projects, rooms or credentials**. "Test" names an existing automated
check that proves the protection, or `GAP` where one must be added.
