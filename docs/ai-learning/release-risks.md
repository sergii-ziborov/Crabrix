# Release risks — Learn Rust with Your Coding Agent

| # | Risk | Evidence | Mitigation |
|---|---|---|---|
| 1 | **Web corpus ahead of the released app.** An agent recommends a lesson the learner's app does not have. | Web/API is built from crabrix-courses `cc73b6d` (839 lessons, catalog-27 content). App Store 1.1.8 bundles catalog 24; the public online catalog is still 23 (`crabrix-courses/catalog.v1.json`). Web-only today: both bridge courses (40 lessons) and `basics/what-is-rust`. | API marks per-lesson `appAvailability` (e.g. `"released"`, `"testflight"`, `"web-only"`) derived from the public catalog's course versions; tools state it in plain words. Keep `index.json` `catalogVersion` and expose the public catalog sequence. |
| 2 | **Remote MCP capacity shared with room sessions.** Academy traffic could take the 64 session slots room agent links need. | `crabrix-sdk/src/remote.ts:26` `maxSessions 64`, one process. | `/mcp/academy` stateless (no session map entry), separate in-flight cap and per-IP rate limit; cache API responses in memory with ETag; room handling untouched. |
| 3 | **Routing `/mcp/academy`.** It currently falls into the agent-link branch and returns 404 "not a Crabrix agent link". | `remote.ts` handle(); repo nginx `site/hetzner/crabrix.com.nginx:91` sends `/mcp/` to `127.0.0.1:3214`. Production ingress on the Hostwatch node was **not inspected** in this audit (only that `crabrix-mcp-remote-1` runs there). | Match `/mcp/academy` exactly before link parsing; test both paths; confirm the node's ingress before release. No nginx change is needed if `/mcp/` already proxies. |
| 4 | **Model reveals answers or writes the solution.** | Lesson pages publish `correctAnswer` and Atlas `expectedAnswer` in reveal blocks. | `teaching` view omits answers; `get_exercise` omits the answer; `get_hint` level 5 requires `revealSolution: true`; teaching contract + skill instruct graded help. This is guidance: a model can still read the public page. |
| 5 | **AI review mistaken for official completion.** | Official completion exists only on-device (`CompilerViewModel.completeLesson`, lab validator). | `review_attempt` returns at most `ai_reviewed`; wording "not recorded in Crabrix"; no tool accepts or returns "verified"; UI copy says progress is recorded only by the app. |
| 6 | **Private grading data leak.** | Harnesses live in `courses/*/checks` and `projects/*`; the site sync reads only `lessons/`. | API built only from `content/courses.json` and an examples export; test that forbidden keys never appear. |
| 7 | **Privacy of copy-prompt / lesson-context text.** | Prompts will be pasted into third-party AI products. | Context contains only public course/lesson IDs, title, goal, public URL and practice options; never room links, keys, progress, project code or account data. No query strings with identifiers. |
| 8 | **Caller-supplied progress treated as fact.** | Web has no progress; app progress is device-only. | Tools label `completedLessonIds` "provided by you, not verified by Crabrix" and never store them. |
| 9 | **Breaking existing MCP clients.** | `test/protocol.test.ts:75` asserts an exact tool list; Cursor and some clients cap tool counts. | Additive namespace; 18 existing tools and schemas unchanged; academy tools only on the unbound local server and the academy endpoint (28 tools locally); bound room server unchanged. Consider an opt-out env flag (`CRABRIX_ACADEMY=0`). |
| 10 | **Hostwatch node near its build floor.** | 23 Nov: first site build refused at 9.80 GB free < 10 GiB minimum; retention freed 559 MB; floor lowered once and restored (`docs/site-deploy.md`). | Before the release: `retention_preview`; ask the owner for more disk or a retention change; do not lower the floor silently. The MCP container rebuild also needs build budget. |
| 11 | **Stale API cache after a content sync.** | Pages are force-dynamic; an API with long cache could lag. | `max-age=300` + ETag on `catalogVersion`; SDK refetches on ETag change. |
| 12 | **Learning-path drift.** A path references a lesson that is later renamed/removed. | Paths are new metadata outside packs. | crabrix-courses test validates every step against current lessons; site build fails on unknown IDs. |
| 13 | **Offline and launch path regressions (Phase 6).** | iOS opens lessons fully offline today. | No AI/MCP dependency in app launch or lesson open; the "Learn with AI" entry is static text + copy actions. |
| 14 | **Feedback/analytics collecting private data.** | Spec §14 events. | Count-only events without code, links, prompts or IDs beyond public lesson IDs; no new analytics SDK in the app. |
| 15 | **Rollback.** | — | Feature is separable: remove `/learn/with-ai/`, the `/learn/` block and API routes, or redeploy the previous site image; SDK academy tools behind a flag; no learner data to migrate back. |
| 16 | **A practice copy that the browser compiler rejects.** Host rustc 1.99 qualified the copies; the Playground runs its own 1.96-dev wasm32-wasip1 toolchain. | `academy/practice-starters.json` `checkedWith`. | Every listed copy was opened and checked in the real browser Playground before release (`docs/ai-learning/evidence/practice-copies.json`); re-run that check after a toolchain or lesson change; a changed lesson text drops its copy automatically. |
| 17 | **A forged or edited AI Learning State.** Anyone can write `officialProgress` by hand. | The file is unsigned by design (the app has no per-device key). | Agents and tools call it "your app export", never verified; it never writes into the app; merges only add. |
| 18 | **New first-party counters on the website.** | Privacy policy said "no third-party visitor analytics". | Counters are first-party aggregates without identifiers; the policy gets a dedicated section (owner reviews before deploy); `CRABRIX_ACADEMY_EVENTS=off` discards them. |
| 19 | **Prefilled-prompt links** (`claude.ai/new?q=`, `chatgpt.com/?q=`) may stop prefilling. | Third-party behaviour. | The buttons copy first, so a client that ignores `q` still has the prompt on the clipboard. |
| 20 | **App status check** adds a request when the Learn with AI screen opens. | iOS privacy label "Data Not Collected". | No identifier, ephemeral session, 5 s timeout, never at launch; offline shows the screen anyway. |
