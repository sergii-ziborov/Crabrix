# Compiler toolchain

Crabrix 1.1 build 11 pins the public [Crabrix source-built toolchain release](https://github.com/sergii-ziborov/crabrix-toolchain/releases/tag/toolchain-2026-10-02.1), `crabrix-rust-2026-10-02.1`. It contains a `rustc.wasm` compiler and `wasm32-wasip1` sysroot built from locked Rust source `abc48c0b8aba37d3f3862a9d5c76eb4e78f90e88` (`1.96.0-dev`). The [app input manifest](../Crabrix/Resources/toolchain.lock.json) pins the release URL, Ed25519 key ID, descriptor digest, source lock, compiler and sysroot digests. The compiler is fetched and verified on the build Mac and bundled in the signed app. An iPhone or iPad does not download compiler updates.

The build recipe is a public fork of [AngelOnFira/wasm-rustc](https://github.com/AngelOnFira/wasm-rustc) with upstream MIT notices and history preserved. The [source lock](https://github.com/sergii-ziborov/crabrix-toolchain/blob/main/toolchain.lock.json) records exact Rust, submodule, backend, WASI SDK, stage0 compiler and Linux amd64 Docker image inputs. This build compiles LLVM from the pinned Rust submodule and uses a verified prebuilt stage0 and WASI SDK. It is a source-built compiler, not a bare-metal bootstrap. Source patches cover narrow integer conversions, high-half multiplication, i128 byte swap and the float-to-i128 return ABI.

The release includes an [Ed25519 signed descriptor](https://github.com/sergii-ziborov/crabrix-toolchain/releases/download/toolchain-2026-10-02.1/toolchain.descriptor.json), per-file sysroot inventory, SHA-256 sums, primary and vendored license notices, provenance, [compatibility results](https://github.com/sergii-ziborov/crabrix-toolchain/releases/download/toolchain-2026-10-02.1/compatibility-results.json) and a [two-build comparison](https://github.com/sergii-ziborov/crabrix-toolchain/releases/download/toolchain-2026-10-02.1/reproducibility-results.json). A public download of every release asset passed the independent verifier. The two clean builds had different raw digests; the report localizes differences, and the release is described as source-pinned rather than byte-identically reproducible. The signing key stays outside all public repositories and the app; the built-in public keyring authenticates the descriptor.

On the pinned CrabrixRuntime and iOS 18.2 Release Simulator, the release compiler passed 13 selected gates: Check, Run, E0502, root features, offline pin, Vendor, all 46 Academy Examples, a three-file CLI using `clap`, `regex`, `hashbrown` and `smallvec`, a route planner using `petgraph` and `itertools`, Stop, bounded output and warning-cache parity. A separate `serde_json` probe failed because the supported Cargo subset does not execute build scripts and `serde_core` needs generated `OUT_DIR` content. The exact tests, artifact IDs and failed probe are in the compatibility report. These are selected Simulator gates; arbitrary crates and physical-device performance are not implied.

`./scripts/bootstrap.sh` validates the app manifest, fetches the public release over HTTPS, verifies the descriptor signature and exact asset hashes, checks every sysroot ZIP entry against its signed inventory, and stages the files for Xcode. `scripts/package_toolchain.py` copies the verified compiler and ZIP into app resources. Cargo cache identity and the Settings version label use the bundled manifest. CoursePacks can include editable source and `Cargo.toml`, but cannot replace the compiler, sysroot or runtime. [Runtime integration](runtime-integration.md) records the separate WasmKit-derived engine revision and its measurements.
