The npm and Rust READMEs include the Crabrix logo, original workspace illustration,
permission infographic and actual phone/tablet/browser captures. Native captures
have equal 360 px display heights. The Rust README now covers library and MCP
installation, a checked source-edit example, Run/Debug permission, development,
interviews, teaching, handoff, expiry, limits and separate artwork terms.

The release source passed Linux/macOS/Windows CI, 27 JS tests, Rust tests,
doctest/example/clippy and Go race/vet. All three public launchers were installed
and completed MCP handshakes. docs.rs returned HTTP 200. Browser checks confirmed
seven images loaded on npm, crates.io and GitHub. A fresh browser image shows a
real disposable room created by the published SDK and its live selection; the
creator ended the room and the private link was not included in the image.

The website serves the byte-identical npm archive and current installation
commands. Eight responsive cases passed on the isolated Hetzner candidate and
production; the account mount, lessons and native App Review build 120 were
preserved. The preceding container remains available for rollback.

At verification, npm's unversioned page still served a CDN-cached 0.3.2 document
with a four-hour max-age. The registry latest tag, fresh install and explicit
[0.3.3 README](https://www.npmjs.com/package/crabrix/v/0.3.3) all showed the new
release. This is recorded as a platform cache limitation, not reported as a
successful refresh of that older document.
