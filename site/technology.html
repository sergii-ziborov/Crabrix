What is actually inside

Most of this page is a list of limits. That is deliberate: a compiler on a phone is only interesting if you can tell exactly which compiler, running under exactly which budgets, and where it stops.

npm for the app’s local web previews

The browser package update bundles Babel standalone 8.0.9 and node-semver 7.8.5 as trusted parsing and version-selection tools. Project JavaScript, TypeScript syntax and JSX are parsed on a serial background worker; project plugins are never loaded into that worker. Generated browser code runs only in the existing isolated, network-blocked WebKit preview.

Explicit npm install / npm ci preparation downloads the reachable browser source graph from the public npm HTTPS registry, verifies archive integrity and saves original modules and licenses as editable project files. Run and Check do not fetch browser dependencies. The terminal maps supported dev/start/build commands to this local browser builder; Node, Bun, arbitrary package scripts, native addons and framework server runtimes are not bundled. See the browser package walkthrough for exact capabilities, lockfiles, budgets and the tested dashboard.

The web Playground

The public Rust Playground compiles and executes in a browser Worker, without login or backend execution. Source folders, file operations, reviewed drag-and-drop imports, live editing, named selections and source export use the same Crabrix themes. The compiler and sysroot are acquired explicitly on the first local Check or Run, verified by SHA-256 and cached on this device.

Browser Cargo is a separate, bounded library profile. Add declarations in Packages or Cargo.toml, then Prepare. The browser resolves normal crates.io library dependencies and additive features, verifies source archives and retains them locally. Run/Check/Debug never download missing crate sources. The root uses the editor’s selected edition; dependencies use their declared editions. Sixteen crates and one version per crate are supported; build scripts, host procedural macros, native linking, Git/path/workspace requirements and target-specific dependency tables are refused. See the Cargo walkthrough, tested versions and exact budgets.

Browser programs have a 64 MiB memory maximum, 1 MiB captured-output limit and 30-second execution deadline. Standard-library compilation has a 45-second deadline; compiling a prepared dependency graph has a two-minute deadline. Source Debug uses checkpoints and bounded previews of String, Vec and concrete local structures; dependency internals are not instrumented. Repeating Run in an already loaded editor can work with verified cached sources while offline; loading the website itself still needs its page assets.

Native project tools

Crabrix 1.1.5 includes the local tools introduced in 1.1.3: selected-entry libtest, bundled rustfmt, Rust symbols and reviewed edits, and libgit2 Git history with explicit HTTPS clone/fetch/fast-forward pull/non-force push. The tests and formatting guide, Rust symbol guide and Git guide describe their installed-version requirements and boundaries. These native tools are not implied by opening the web Playground.

Shared rooms and AI agents

No account is needed. The relay retains AES-256-GCM ciphertext in memory until the chosen expiry, one hour by default and at most 24 hours; a restart can end a room earlier. Up to four participants share text, cursors and selections. Packages and compiled artifacts are not transferred. Crabrix MCP 0.5.0 and the website’s optional remote MCP connect an agent to a room. The local SDK keeps its key after # on the agent’s computer. The optional website remote MCP decrypts that room in server memory while connected, after an explicit warning. Neither service compiles or executes the project.

Execution permission starts off and is scoped to one selected device or browser, supported operations and at most ten minutes. The agent-controlled profile remains manifest-free standard-library Rust and local modules; it cannot download packages, attach private inputs or run a shell. A reported output preview never starts execution on an observer. Manual browser Cargo results remain local. Read the connection and permission steps.

Academy content

A new installation offers all seven courses from a signed public catalog; the separate Code Examples download contains 46 editable projects. Existing learners updating from the old Academy receive all seven signed transition packs locally, preserving their offline course access. Later course versions are data-only signed CoursePacks from the public course repository. The app shows the size before a requested update, verifies its signature and file hashes, then switches the installed version. A CoursePack cannot update the compiler or runtime. An installed course remains readable without a network; crate exercises also need their Cargo dependencies prepared for offline builds.

Cargo, and the part of it that works

Crabrix implements the dependency pipeline itself rather than shipping Cargo: sparse-index resolution against crates.io, SemVer ranges, feature unification, resolver 1/2/3 semantics, rust-version checks, target cfg filtering, a real Cargo.lock, SHA-256-verified downloads, dependency compilation, and --extern linking.

Every package is labelled from real build outcomes: Link verified when its artefacts linked, Check verified when only metadata was produced, Needs review, or Unsupported with the reason.

What it cannot do

  • The local source debugger steps synchronous and async Rust statements and shows active poll frames, primitive values and bounded String, Vec and concrete local struct previews. Const bodies, macro expansions, dependency internals and arbitrary Rust memory inspection are not supported. See the debugger guide.
  • Selected-entry unit tests use local libtest; integration targets, dev-dependency graphs and doctests are outside that profile. Ignored tests are skipped and should_panic is unsupported in panic-abort builds.
  • Native Git supports local commits and explicit non-force HTTPS push. SSH, LFS, submodules, rebase and arbitrary hooks are outside its profile.
  • A first compile is interpreted WebAssembly, so it is slower than a laptop. Identical repeat runs come from a local artifact cache.

Privacy, stated as a property of the build

There is no required account, analytics SDK, advertising, or tracking. An off-by-default Game Center switch in Profile shares a numeric rating and achievement ladder progress with Apple; Crabrix runs no board server. Other network requests include selected course downloads, package downloads, repository operations and temporary Playground sharing you ask for. Website accounts and optional remote MCP are separate website features; see the privacy policy.

These measurements describe an experimental full-LTO compiler and a corrected software-bounds interpreter path on iPhone 13 mini, iOS 26.5. They do not describe the compiler currently bundled in the App Store version. Dependency source archives were prepared before timing; every measured dependency artifact was absent at the start. Compilation and execution took place on the phone.
